### sFO-MLA

Implementations of the stochastic first-order Mirror Langevin Algorithm and its warm-started two-loop variant for constrained sampling, including applications to Bayesian mixture weights and Poisson graphical models.

[Code](https://github.com/antik015/sFO-MLA) · [Paper](https://arxiv.org/abs/2610.09402)

### CR-MRF for Ordinal Preference Data

Code for fitting covariate-dependent consecutive-ratio Markov random fields to multivariate ordinal preference data, with comparisons to pseudo-likelihood and Plackett--Luce approaches.

[Code](https://github.com/antik015/CR-MRF-ordinal-preference-data) · [Paper](https://arxiv.org/abs/2610.09070)

### Exact and Approximate MCMC for Doubly-Intractable Graphical Models

Code accompanying work on exact and approximate MCMC methods for probabilistic graphical models with intractable normalizing constants, leveraging the corresponding independence model to construct efficient samplers.

[Code](https://github.com/antik015/exact-approx-mcmc) · [Paper](https://proceedings.mlr.press/v300/chen26e.html) · [arXiv](https://arxiv.org/abs/2510.03587)

### ExponentialGM

R code for likelihood-based inference in fully and partially observed exponential-family graphical models with intractable normalizing constants.

[Code](https://github.com/antik015/ExponentialGM) · [Paper](https://arxiv.org/abs/2404.17763)

### EBayes-Integration

R functions for empirical Bayes data integration in multi-response regression problems.

[Code](https://github.com/antik015/EBayes-Integration) · [Paper](https://www3.stat.sinica.edu.tw/statistica/fp/SS-2025-0115.html)

### OCal

R code for orthogonal calibration via posterior projections, including applications to computer model calibration and the Schwarzschild model.

[Code](https://github.com/antik015/OCal) · [Paper](https://arxiv.org/abs/2404.03152)

### bigMVP

Software for scalable two-stage Bayesian inference in high-dimensional multivariate probit models for multivariate binary responses.

[Code](https://github.com/antik015/bigMVP) · [Paper](https://arxiv.org/abs/2106.02127)

### NN-DM

R code for nearest-neighbor Dirichlet mixtures, a scalable Bayesian nonparametric model for multivariate density estimation.

[Code](https://github.com/antik015/NN-DM) · [Paper](https://arxiv.org/abs/2003.07953)

### Fractional Probit Model

R code for Bayesian semiparametric long-memory modeling of discretized event data.

[Code](https://github.com/antik015/Fractional-Probit-Model) · [Paper](https://arxiv.org/abs/2004.08309)

### Simultaneous Dimension Reduction and Variable Selection

MATLAB code for Bayesian sparse multiple regression with simultaneous rank reduction and variable selection.

[Code](https://github.com/antik015/Simultaneous-Dimension-Reduction-and-Variable-Selection) · [Paper](https://arxiv.org/abs/1612.00877)

### Fast Sampling of Gaussian Posteriors

MATLAB implementation of a fast exact sampler for Gaussian posterior distributions arising in high-dimensional regression with Gaussian scale-mixture priors.

[Code](https://github.com/antik015/Fast-Sampling-of-Gaussian-Posteriors) · [Paper](https://arxiv.org/abs/1506.04778)

### horseshoe

R package for high-dimensional regression and normal-means estimation using horseshoe shrinkage priors, including the fast Gaussian posterior sampling strategy above.

[CRAN](https://cran.r-project.org/package=horseshoe) · [Paper](https://arxiv.org/abs/1506.04778)

### Truncated Normal CDF

Rcpp implementation for computing probabilities of truncated multivariate Gaussian distributions using importance sampling.

[Code](https://github.com/antik015/Truncated-normal-cdf)
